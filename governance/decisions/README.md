# Governance Decision Records

Kanonischer Verwahrort gemäß ADR-0064. Dieser Bereich ist kein Runtime Store,
keine Datenbank und keine automatische Sammlung. Die typisierten Verträge sind
implementiert; tatsächlich gefasste institutionelle Entscheidungen werden nur
nach einem eigenen ausdrücklichen Dokumentationsauftrag abgelegt.

Der Bereich enthält ausschließlich ausdrücklich beauftragte, gegenwärtige
Decision Records. Der erste Record dokumentiert die begrenzte institutionelle
Implementierungsfreigabe `GOV-B2-NORMATIVE-STATUS-CONSOLIDATION-APPROVAL-V1`.
Es werden weiterhin keine historischen Records erzeugt oder rekonstruiert;
insbesondere entsteht kein ADR-0059-Ratifikationsnachweis.
