# Governance Incident Evidence

Kanonischer Verwahrort gemäß ADR-0064. Dieser Bereich ist strikt von Runtime
Incidents nach ADR-0052, Observation, Audit und Operational Memory getrennt.
Er ist keine Überwachungs-, Mitarbeiter- oder Nutzerakte und besitzt keine
Sanktions-, Sperr-, Autorisierungs- oder Runtime-Wirkung.

Derzeit enthält der Bereich keine Incident-Evidence-Artefakte. Bestehende
Prozessvorfälle werden nicht automatisch migriert oder rückwirkend umgedeutet.
Die implementierten Verträge erzeugen, klassifizieren oder speichern keine
Incidents automatisch.
