# Architecture Workflows

Dieser Bereich enthält ausschließlich reproduzierbare Arbeitsartefakte des
Architecture Workflow:

- eingereichte Proposals,
- Integrator-Analysen,
- nicht bindende Entscheidungsvorlagen,
- ausdrücklich bestätigte Chief-Architect-Entscheidungen,
- daraus erzeugte Codex-Aufträge.

Ein Workflow-Verzeichnis ist kein MDR, keine ADR und keine automatische
Architekturfreigabe. Nur der Chief Architect entscheidet. Der Orchestrator
wartet auf je eine passende Entscheidung pro Proposal und erzeugt vorher
keinen Codex-Auftrag.

Die Ablage verändert keine verbindliche Architektur und führt weder Codex
noch Tests, Commits oder externe Dienste aus.
