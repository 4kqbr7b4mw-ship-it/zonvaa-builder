## Functional changes

- The architecture process now has one state-aware architecture run entry point for new proposals and confirmed decisions.
- Analysis emits one compact joint Chief Architect decision proposal and remains waiting without a confirmed decision.
- Complete confirmed decisions automatically produce Decision Records, update the workflow state, and generate the Codex prompt in the same run.

## Technical changes

- Added immutable ArchitectureRunResult and versioned ArchitectureWorkflow schema 2.0 with topic and one canonical decision template.
- Added deterministic topic-bound workflow identities, compact multi-proposal template rendering, and validated decision batching.
- Preserved schema 1.0 loading and the existing workflow subcommands for compatibility.

## Decisions

- Architecture Workflow v2 extends the existing Integrator, store, decisions, and prompt builder instead of creating a parallel workflow.
- Each proposal retains its own explicit ChiefArchitectDecision while one run command orchestrates all valid state transitions.
- The workflow may stop only while waiting for human decisions or after the Codex prompt has been generated; it never decides or implements.
