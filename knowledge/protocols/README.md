# Runtime Protocols

Dieses Verzeichnis enthält automatisch erzeugte Laufzeitprotokolle.

Ein Protokoll beschreibt den tatsächlichen Verlauf einer Builder-Session.

Es enthält ausschließlich bestätigte Ereignisse.

Beispiele:

- gestartete Commands
- erfolgreiche Tests
- fehlgeschlagene Tests
- Architekturentscheidungen
- geänderte Dateien
- bestätigte Fehlerbehebungen
- Runtime-Informationen

Ein Protokoll ist kein Handover.

Der Handover entsteht zukünftig aus:

- Runtime-Protokoll
- aktueller Session
- Constitution
- ADRs
- dauerhaftem Projektwissen
